**Deutsch-Teachers-app** یک برنامه دسکتاپ برای کمک به معلمان زبان است تا کارهای آموزشی و اجرایی روزانه‌شان را در محیطی یکپارچه مدیریت کنند. برنامه با هدف ساده‌تر کردن پیگیری زبان‌آموزها، کلاس‌ها، حضور و غیاب، پرداخت‌ها و روند یادگیری طراحی شده است.

این پروژه مخصوص معلمان زبان آلمانی است؛ هر مدرس می‌تواند مشخصات پروفایل و داده‌های آموزشی خودش را در برنامه ثبت کند. کتاب‌های آموزشی آلمانی و سطح‌های CEFR از A1 تا C2 در نظر گرفته شده‌اند.

> **تمرکز برنامه:** نظم بیشتر در کارهای روزانه، پیگیری روشن‌تر پیشرفت زبان‌آموزها و دسترسی سریع‌تر به اطلاعات کلاس‌ها.

## 🇬🇧 English

**From managing students and planning classes to tracking payments and learning progress, all in one desktop app.**

> **Note on the interface language:** the app was built for Persian-speaking German teachers, so the user interface is in Persian (right-to-left). This page explains what the app does for readers who do not read Persian.

### About

**Deutsch-Teachers-app** is a Windows desktop application that helps teachers of German manage their daily teaching and admin work in one place: students, classes, attendance, payments and learning progress. It started as a tool I built for my own German teacher and was later published as a general version for other teachers.

Each teacher enters their own profile and data. German coursebooks and the CEFR levels A1 to C2 are built into the student records.

### Features

| Area | What it does |
| --- | --- |
| **Dashboard** | Today's classes, number of students, outstanding payments and notes at a glance |
| **Students** | Contact details, CEFR level, coursebook, current lesson, progress, notes and photo |
| **Classes and calendar** | Private and group classes, scheduling, attendance |
| **Payments** | Per-lesson, monthly or package payments, in euro and toman |
| **Whiteboard** | Pen, highlighter, shapes, text, eraser, undo/redo, zoom and pan for use during lessons |
| **Reports** | Overview of classes, attendance, progress and finances |
| **Backups** | Automatic backups, manual backup and restore |
| **Profile and settings** | Teacher profile and picture |

### Install

The Windows installer is built by GitHub Actions.

1. Open the [Actions page](https://github.com/ebixs/Deutsch-Teachers-app/actions).
2. Open the latest successful run named **Build Deutsch-Teachers-app for Windows**.
3. Download the artifact **Deutsch-Teachers-app-Windows**. It contains the installer (`Deutsch-Teachers-app_Setup.exe`) and a portable version (`Deutsch-Teachers-app_Portable.exe`).
4. Run the installer, or start the portable version directly.

The installer is not code-signed, so Windows SmartScreen may show a warning. There is no ready-made release download yet; the build artifacts are the only way to get the app.

### Run from source

```bash
npm install
npm start          # starts Electron
npm run dist       # builds the Windows installer into dist/
```

### Data and privacy

- All data stays on your computer in a single JSON file: `%APPDATA%\Deutsch-Teachers-app\deutsch-teachers-data.json`. Normal use does not need an internet connection.
- Writes are atomic and the previous copy is kept as a `.bak` file.
- The app makes automatic backups (the 14 most recent are kept) in the `backups` folder next to the data file. Manual backups use the `.albackup` format. Before a restore, the app saves a copy of the current state.
- Keep backups in a safe place, separate from the main computer, and mind who else can use a shared computer, because the data contains student information.

### Tech stack

Electron (main process and preload script) with a single-page interface in plain HTML, CSS and JavaScript. Installers are built with electron-builder (NSIS and portable) in a GitHub Actions workflow. The app allows only one running instance, so two copies cannot write to the same data file.

## 🇩🇪 Deutsch

**Von der Verwaltung der Lernenden und der Kursplanung bis zur Zahlungsverfolgung und zum Lernfortschritt: alles in einer Desktop-Anwendung.**

> **Hinweis zur Sprache der Oberfläche:** Die Anwendung wurde für persischsprachige Deutschlehrkräfte entwickelt. Die Benutzeroberfläche ist deshalb auf Persisch (von rechts nach links). Diese Seite erklärt für Leserinnen und Leser ohne Persischkenntnisse, was die Anwendung kann.

### Über das Projekt

**Deutsch-Teachers-app** ist eine Windows-Desktop-Anwendung, mit der Lehrkräfte für Deutsch ihren Unterrichts- und Verwaltungsalltag an einem Ort organisieren: Lernende, Kurse, Anwesenheit, Zahlungen und Lernfortschritt. Ich habe sie zuerst für meinen eigenen Deutschlehrer gebaut und später als allgemeine Version für andere Lehrkräfte veröffentlicht.

Jede Lehrkraft trägt ihr eigenes Profil und ihre eigenen Daten ein. Deutsche Lehrbücher und die GER-Niveaus A1 bis C2 sind in den Datensätzen der Lernenden vorgesehen.

### Funktionen

| Bereich | Was er leistet |
| --- | --- |
| **Dashboard** | Kurse des Tages, Anzahl der Lernenden, offene Zahlungen und Notizen auf einen Blick |
| **Lernende** | Kontaktdaten, GER-Niveau, Lehrbuch, aktuelle Lektion, Fortschritt, Notizen und Foto |
| **Kurse und Kalender** | Einzel- und Gruppenunterricht, Terminplanung, Anwesenheit |
| **Zahlungen** | Zahlung pro Stunde, monatlich oder als Paket, in Euro und Toman |
| **Whiteboard** | Stift, Textmarker, Formen, Text, Radierer, Rückgängig/Wiederholen, Zoom und Verschieben für den Unterricht |
| **Berichte** | Überblick über Kurse, Anwesenheit, Fortschritt und Finanzen |
| **Sicherungen** | Automatische Sicherung, manuelle Sicherung und Wiederherstellung |
| **Profil und Einstellungen** | Profil und Bild der Lehrkraft |

### Installation

Das Windows-Installationsprogramm wird von GitHub Actions erstellt.

1. Die [Actions-Seite](https://github.com/ebixs/Deutsch-Teachers-app/actions) öffnen.
2. Den neuesten erfolgreichen Lauf **Build Deutsch-Teachers-app for Windows** öffnen.
3. Das Artefakt **Deutsch-Teachers-app-Windows** herunterladen. Es enthält das Installationsprogramm (`Deutsch-Teachers-app_Setup.exe`) und eine portable Version (`Deutsch-Teachers-app_Portable.exe`).
4. Das Installationsprogramm ausführen oder die portable Version direkt starten.

Das Installationsprogramm ist nicht signiert, daher kann Windows SmartScreen eine Warnung anzeigen. Es gibt noch keinen fertigen Release-Download; die Build-Artefakte sind derzeit der einzige Weg, die Anwendung zu erhalten.

### Aus dem Quellcode starten

```bash
npm install
npm start          # startet Electron
npm run dist       # erstellt das Windows-Installationsprogramm in dist/
```

### Daten und Datenschutz

- Alle Daten bleiben auf dem eigenen Computer in einer einzigen JSON-Datei: `%APPDATA%\Deutsch-Teachers-app\deutsch-teachers-data.json`. Für den normalen Gebrauch ist keine Internetverbindung nötig.
- Schreibvorgänge sind atomar; die vorherige Fassung bleibt als `.bak`-Datei erhalten.
- Die Anwendung legt automatische Sicherungen an (die 14 neuesten bleiben erhalten), und zwar im Ordner `backups` neben der Datendatei. Manuelle Sicherungen verwenden das Format `.albackup`. Vor einer Wiederherstellung speichert die Anwendung eine Kopie des aktuellen Stands.
- Sicherungen sollten an einem sicheren Ort getrennt vom Hauptrechner liegen. Bei gemeinsam genutzten Computern ist zu beachten, wer Zugriff hat, denn die Daten enthalten Angaben zu Lernenden.

### Technik

Electron (Hauptprozess und Preload-Skript) mit einer Single-Page-Oberfläche in reinem HTML, CSS und JavaScript. Die Installationsprogramme entstehen mit electron-builder (NSIS und portabel) in einem GitHub-Actions-Workflow. Es läuft immer nur eine Instanz der Anwendung, damit nicht zwei Kopien in dieselbe Datendatei schreiben.
