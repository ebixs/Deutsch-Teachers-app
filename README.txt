

# Deutsch-Teachers-app

### یک فضای کاری منظم برای معلمان زبان آلمانی

**از مدیریت زبان‌آموزها و برنامه‌ریزی کلاس‌ها تا پیگیری پرداخت‌ها و پیشرفت آموزشی — همه در یک برنامه دسکتاپ.**

مشاهده مخزن: https://github.com/ebixs/Deutsch-Teachers-app · گزارش مشکل: https://github.com/ebixs/Deutsch-Teachers-app/issues · ساخت نسخه ویندوز: https://github.com/ebixs/Deutsch-Teachers-app/actions



------------------------------------------------------------

## ✨ درباره برنامه

**Deutsch-Teachers-app** یک برنامه دسکتاپ برای کمک به معلمان زبان است تا کارهای آموزشی و اجرایی روزانه‌شان را در محیطی یکپارچه مدیریت کنند. برنامه با هدف ساده‌تر کردن پیگیری زبان‌آموزها، کلاس‌ها، حضور و غیاب، پرداخت‌ها و روند یادگیری طراحی شده است.

این پروژه مخصوص معلمان زبان آلمانی است؛ هر مدرس می‌تواند مشخصات پروفایل و داده‌های آموزشی خودش را در برنامه ثبت کند. کتاب‌های آموزشی آلمانی و سطح‌های CEFR از A1 تا C2 در نظر گرفته شده‌اند.

> **تمرکز برنامه:** نظم بیشتر در کارهای روزانه، پیگیری روشن‌تر پیشرفت زبان‌آموزها و دسترسی سریع‌تر به اطلاعات کلاس‌ها.

## 🎯 امکانات اصلی

| بخش | چه کاری انجام می‌دهد؟ |
| --- | --- |
| **داشبورد** | مرور سریع کلاس‌های روز، تعداد زبان‌آموزها، پرداخت‌های باقی‌مانده و یادداشت‌ها |
| **مدیریت زبان‌آموزها** | ثبت اطلاعات، سطح زبان، کتاب، درس فعلی، پیشرفت، یادداشت و عکس |
| **کلاس‌ها و تقویم** | برنامه‌ریزی کلاس‌های خصوصی و گروهی، تعیین زمان و ثبت حضور و غیاب |
| **مدیریت پرداخت‌ها** | ثبت پرداخت‌های جلسه‌ای، ماهانه یا پکیجی با پشتیبانی از یورو و تومان |
| **تخته آموزشی** | ابزارهای قلم، هایلایتر، شکل‌ها، متن، پاک‌کن، Undo/Redo، بزرگ‌نمایی و جابه‌جایی صفحه |
| **گزارش‌ها** | مرور اطلاعات مربوط به کلاس‌ها، حضور و غیاب، پیشرفت و وضعیت مالی |
| **پشتیبان‌گیری** | ذخیره خودکار، تهیه نسخه پشتیبان دستی و بازیابی فایل پشتیبان |
| **پروفایل و تنظیمات** | شخصی‌سازی اطلاعات و تصویر پروفایل معلم |

## 💻 نصب و اجرا

نسخه نصب ویندوز از طریق بخش **Actions** ساخته می‌شود. پس از تکمیل موفق فرایند ساخت، فایل‌های خروجی در قسمت **Artifacts** همان اجرای GitHub Actions در دسترس خواهند بود.

1. به صفحه ساخت‌های ویندوز: https://github.com/ebixs/Deutsch-Teachers-app/actions بروید.
2. آخرین اجرای موفق با عنوان **Build Deutsch-Teachers-app for Windows** را باز کنید.
3. از بخش **Artifacts** فایل خروجی ویندوز را دریافت کنید.
4. اگر فایل نصب در خروجی موجود بود، آن را اجرا کنید و مراحل نصب را ادامه دهید.

**توجه:** تا زمانی که یک اجرای موفق و فایل خروجی آن تأیید نشده باشد، وجود فایل نصب آماده را نمی‌توان تضمین کرد.

## 🔐 اطلاعات و حریم خصوصی

- برنامه برای کارهای روزمره به‌گونه‌ای طراحی شده است که داده‌ها روی همان رایانه نگهداری شوند و استفاده معمول به اینترنت وابسته نباشد.
- از اطلاعات مهم خود به‌طور منظم نسخه پشتیبان تهیه کنید.
- نسخه پشتیبان را در مکانی امن و جدا از رایانه اصلی نگه دارید.
- اگر از رایانه مشترک استفاده می‌کنید، به دسترسی دیگران به اطلاعات زبان‌آموزها توجه داشته باشید.

## 🧑‍🏫 مناسب چه کسانی است؟

- معلمان زبان آلمانی با کلاس‌های خصوصی
- مدرس‌های زبان آلمانی که کلاس‌های گروهی برگزار می‌کنند
- معلمان آلمانی که می‌خواهند برنامه کلاس‌ها و حضور و غیاب را منظم‌تر ثبت کنند
- مدرس‌های آلمانی که به پیگیری پرداخت‌ها و روند آموزشی زبان‌آموزها نیاز دارند
