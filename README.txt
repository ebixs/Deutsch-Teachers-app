AysudaLern — German Learning Studio
راهنمای ساده استفاده

────────────────────────
۱) نصب
────────────────────────
۱. فایل AysudaLern_Setup.exe را دوبار کلیک کنید.
۲. اگر ویندوز پیام «Windows protected your PC» نشان داد، روی «More info» و بعد «Run anyway» بزنید.
   (این پیام فقط به این دلیل است که برنامه یک هدیه شخصی است و در فروشگاه ثبت نشده؛ برنامه کاملاً سالم است.)
۳. Next ← Install ← Finish
۴. از میانبر روی دسکتاپ یا منوی Start برنامه را باز کنید.

برنامه برای استفاده روزمره به اینترنت نیاز ندارد و اطلاعات فقط روی همین کامپیوتر ذخیره می‌شود.

────────────────────────
۲) داشبورد
────────────────────────
کلاس‌های امروز، تعداد زبان‌آموزها، پرداخت‌های باقی‌مانده و یادداشت سریع.
پیام خوشامدگویی (Guten Morgen / Guten Tag / Guten Abend) بر اساس ساعت کامپیوتر نمایش داده می‌شود.

────────────────────────
۳) زبان‌آموزها
────────────────────────
دکمه «زبان‌آموز جدید» را بزنید و نام، سطح (A1 تا C2)، کتاب، درس فعلی، پیشرفت، یادداشت و عکس را وارد کنید.
هر زبان‌آموز بعداً قابل ویرایش و حذف است. جستجو و فیلتر بر اساس سطح هم دارد.

────────────────────────
۴) کلاس‌ها و تقویم
────────────────────────
دکمه «کلاس جدید» را بزنید:
- نوع کلاس: خصوصی یا گروهی
- زبان‌آموز را انتخاب کنید
- کتاب را انتخاب کنید (مثلاً Menschen A1.1) و بعد درس همان کتاب (مثلاً Lektion 7)
- تاریخ و ساعت را وارد کنید و ذخیره کنید
در تقویم هفتگی، هر سطح زبان یک رنگ مخصوص دارد (راهنمای رنگ‌ها بالای تقویم است).
حضور و غیاب هر کلاس را می‌توانید در «لیست کلاس‌ها» ثبت کنید.

────────────────────────
۵) پرداخت‌ها
────────────────────────
پرداخت‌ها را با یورو (€) یا تومان ثبت کنید؛ نوع پرداخت: جلسه‌ای، ماهانه یا پکیج.
جمع دریافتی و مانده در بالای صفحه دیده می‌شود.

────────────────────────
۶) Whiteboard
────────────────────────
تخته‌ای برای تدریس: انتخاب، قلم، هایلایتر، خط، مستطیل، دایره، متن، پاک‌کن، Undo / Redo، Zoom، حرکت دادن صفحه و شبکه.
- ابزار T: روی هر نقطه کلیک کنید و مستقیم بنویسید. Enter = خط بعد.
- متن و شکل‌ها قابل انتخاب، جابه‌جایی، تغییر اندازه و حذف هستند.
- دکمه تمام‌صفحه دارد؛ با کلید Esc از آن خارج می‌شوید.
- «ذخیره تخته» محتوای تخته را نگه می‌دارد.

────────────────────────
۷) گزارش‌ها
────────────────────────
نمای کلی پیشرفت زبان‌آموزها، تعداد کلاس‌ها، حضور و وضعیت مالی.

────────────────────────
۸) اطلاعات و Backup (مهم)
────────────────────────
- اطلاعات به‌صورت خودکار و همان لحظه ذخیره می‌شود؛ لازم نیست دکمه‌ای بزنید.
- هر روز یک Backup خودکار گرفته می‌شود و ۱۴ نسخه آخر نگه داشته می‌شود.
- Backup دستی: تنظیمات ← «ساخت Backup» ← فایلی با پسوند .albackup روی فلش یا هارد ذخیره کنید.
  پیشنهاد: هفته‌ای یک بار این کار را بکنید و فایل را جای دیگری (فلش/ایمیل خودتان) هم نگه دارید.
- بازیابی: تنظیمات ← «بازیابی» ← فایل .albackup را انتخاب کنید.
  (قبل از بازیابی، یک نسخه از اطلاعات فعلی هم نگه داشته می‌شود.)
- اگر ویندوز عوض شد یا برنامه را دوباره نصب کردید، با همان فایل Backup همه چیز برمی‌گردد.
- حذف برنامه (Uninstall) اطلاعات شما را پاک نمی‌کند.

محل ذخیره اطلاعات:
C:\Users\<نام کاربری>\AppData\Roaming\AysudaLern

────────────────────────
۹) تغییر عکس‌ها
────────────────────────
تنظیمات ← «تغییر عکس» برای عکس استاد. عکس هر زبان‌آموز هم هنگام ویرایش او قابل تغییر است.
